スタッフ管理（GitHub ＋ Cloudflare・チーム共有版）セットアップ手順
=================================================================
全員が、スマホ・PCのどこからでも同じ最新データを見て・更新できます（他の端末へ十数秒で自動反映）。
無料枠で動きます。アクセスキー：zenko1234（変更方法は最後）

■ 構成（1つのCloudflare Workerで完結）
  public/   画面（index.html など）
  src/      データ保存・同期のサーバー処理（Durable Objects）＋初期データ（名簿など）
  wrangler.toml / package.json   Cloudflare用の設定

■ 手順（所要 約15分・すべてブラウザだけでOK）
 【1】GitHub に非公開リポジトリを作る  ★必ず Private
   ・名簿の個人情報とアクセスキーがコードに入っているため、公開(Public)にしないでください
   1. GitHub → New repository → 名前（例：staff-app）→ Private → Create
   2. 「uploading an existing file」→ このフォルダの中身（public / src / wrangler.toml / package.json / .gitignore）を
      フォルダごとドラッグ → Commit changes
      （src/index.mjs は約1.4MBですがアップロードできます）
 【2】Cloudflare でリポジトリをつなぐ
   1. https://dash.cloudflare.com に無料登録 → 左メニュー「Workers & Pages」→ Create → 「Import a repository（Connect to Git）」
   2. GitHub と連携 → 先ほどのリポジトリを選択
   3. 設定はそのまま（Build command 空／Deploy command は npx wrangler deploy）→ Save and Deploy
   4. 完了後、https://staff-app.（あなたのサブドメイン）.workers.dev のURLが出ます
 【3】みんなに共有
   ・URLの末尾に ?k=zenko1234 を付けて送ると、キー入力なしで開けます
     例）https://staff-app.xxxx.workers.dev/?k=zenko1234
   ・スマホはホーム画面に追加しておくと便利です

■ 旧Netlify版のデータを引き継ぐ
   ・同梱の初期データ＝旧版の元データ（Excel＋キャスナビ名簿）が、最初のアクセス時に自動で入ります
   ・旧版で画面から入力した分は、旧アプリをPCで開く →「⇅ CSV」→「バックアップを書き出す」で保存し、
     新アプリをPCで開く →「⇅ CSV」→ 復元 で取り込んでください（1回だけ）

■ 更新するとき
   ・画面を直す：GitHub の public/index.html を差し替え → 自動で再公開されます（保存データはそのまま）
   ・保存データは Cloudflare 側に残ります。Worker を作り直さないでください（データは Worker に紐づきます）

■ アクセスキーを変える
   Cloudflare → Workers & Pages → staff-app → Settings → Variables and Secrets →
   TOKEN という名前で新しいキーを追加 → Deploy。
   （未設定の間は zenko1234 です。10回続けて間違えると10分ロックされます）

■ スタッフの削除と「復活させない」仕組み
  ・名簿の各カードの 🗑、スタッフ詳細の「🗑 削除」、編集画面の「🗑 このスタッフを削除」から削除できます（確認画面あり）
  ・名簿の「☑ 選んで削除」：カードをタップして複数チェック →「表示中をすべて選ぶ」も可 → 下の「🗑 選んだ○名を削除」で一括削除
  ・名簿のカードに常時「🗑 削除」ボタンがあります（1名ずつ）
  ・「🗑 退職者を整理」ボタン：退職扱いの人を一覧からチェックして、まとめて削除できます
  ・削除したIDは「削除済みリスト」としてサーバーに保存され、全端末に共有されます
  ・元データ（キャスナビCSV・簡易CSV）を何度読み込み直しても、削除済みのIDは取り込まれません（プレビューに「削除済みのため除外 ○名」と表示）
  ・戻したいとき：「⇅ CSV」→「削除済みスタッフ」の「戻す」→ もう一度CSVを取り込むと名簿に戻ります
    （または、CSV取り込み画面の「削除済みの人も復活させて取り込む」にチェック）
  ・削除すると、その人のシフトの割り当ても消えます

■ 検索とCSV取り込みの照合
  ・検索は「髙/高」「﨑/崎」「邊・邉/辺」「齋・齊/斎」など、旧字・異体字の違いを同じ字として探します（苗字だけ／名前だけでもOK）
  ・検索結果は、絞り込み中は最大500名まで全件表示します（前方一致の人が上に出ます）
  ・「⇅ CSV」でファイルを選ぶと、「このCSVの中を名前で探す」欄で、その人がCSVのどの行にいて、取り込まれるか（新規／既存／削除済み／不備／ID重複）を確認できます
  ・取り込まれない行（不備・ID重複・削除済み）と、新しく追加される人の一覧も開いて確認できます

■ 現場ごと・日ごとのスケジュール編集
  ・シフト表のカレンダーで現場（日）をタップ →「✏ この現場のスケジュール・クライアントを編集」で、その日のその現場だけが開きます
    （「この現場の全日程を表示」で同じ現場の他の日も、「月全体を表示」で1か月分も見られます）
  ・カレンダーの「＋」（日付のマス）：その日だけの画面で現場を追加できます
  ・「⚙ 現場スケジュール編集」：現場の絞り込み（シフト表で現場を選んでいればその現場だけ）。画面内の「現場：」で切り替えも可能
  ・その現場に日程を追加するときは、会社・詳細・時間・人数を引き継いで入力済み。日付を選んで「＋ 追加」だけ（追加後は翌日が初期値）
  ・月の切り替え・追加は、画面内の「📆 月の切り替え・追加」にまとめました

■ 請求・支払のチェックボックス
  ・シフト表（カレンダー／一覧／担当表）の「請求」「支払」は、□ のチェックボックスです。クリックで ☑（済）⇔ □（未）が切り替わり、すぐ保存・全端末に反映されます
  ・緑の ☑ ＝済、白い □ ＝未。表示の絞り込み「請求書／支払 未チェックのみ」も使えます

■ Googleカレンダー連携（現場名＋時間）
  ・1件ずつ：「📅 追加」「📅 カレンダーに追加」を押すと、Googleカレンダーの予定登録画面が開きます（現場名・日付・開始〜終了時間が入力済み）。「保存」を押すだけ
    場所：シフト表の「一覧」の右端／現場をタップした画面／「現場スケジュール編集」の各行
  ・まとめて：シフト表の「📅 カレンダー書き出し」（その月。現場を絞っていればその現場だけ）、または「現場スケジュール編集」の「全期間をカレンダー(.ics)」
    → ダウンロードした .ics ファイルを、Googleカレンダー（PCのブラウザ）の 設定 →「インポート／エクスポート」→「インポート」で選ぶと、一括で取り込めます
    （iPhoneのカレンダー、Outlook は .ics をタップ／ダブルクリックで取り込み可）
  ・時間が未入力の現場は「終日」、終了時間だけが空なら「1時間」、終了が開始より前なら翌日の終了として登録します
  ・同じ .ics を何度取り込んでも、予定ごとの固有IDがあるので、多くの場合は重複せず上書きされます（念のためインポート後に確認してください）

■ 複数日の一括登録／過去スケジュールのコピー（⚙ 現場スケジュール編集）
  ・「📅 複数日をまとめて登録」：日付のマスをタップして複数選択（毎日／平日／土日／範囲指定ボタンあり）→「＋ 選んだ○日分をまとめて追加」
    同じ現場名・人数・時間・会社・詳細で一気に登録します。すでに同じ現場がある日は自動で除外します
  ・スタッフの割り当ては登録後に、日ごと（シフト表で日付をタップ）に個別設定できます（コピーしません）
  ・「📋 過去のスケジュールからコピー」：現場を選ぶと過去の予定が新しい順に出ます →「📋 コピー」で入力欄に流用（編集してから、日付を選んで追加）
  ・登録済みの各行の「📋 コピーして追加」でも、その内容を入力欄に流用できます
  ・「月まるごとコピー」：コピー元の月（と現場）を選んで「○月にコピー」で、同じ日付の予定を一括作成（人数・時間・会社・詳細を引き継ぎ）

■ 配置依頼書・支払いリスト（Excel）出力
  シフト表の「📄 配置依頼書(Excel)」（月ごと・現場フィルタ対応）、または現場をタップした画面の「📄 配置依頼書(Excel)」から出力。
  「確定」のスタッフを現場×日ごとに1シートで、No./ID/氏名/電話番号/出勤/退勤/拘束/休憩/実働/通常・残業・深夜/移動手当/手当/合計金額 の順に書き出します。
  出勤・退勤は現場スケジュールの開始/終了時間、休憩の初期値は60分（出力画面で変更可）。計算はExcelの数式なので、出力後に時刻を直せば自動で再計算されます。
  基本時給(初期1550円)・給与支給日・担当は出力画面で入力（この端末に記憶されます）。

■ ログアウト
  画面右上（ヘッダー）の「🔓 ログアウト」を押すと、未保存の変更を送信したうえで、この端末のアクセスキーを破棄し、アクセスキー入力画面に戻ります。
  共有端末を使ったあとはログアウトしてください。（Casnavi CSVをこの端末に取り込んでいる場合、そのデータは端末内に残ります）

■ 祝日の自動判定（赤字・祝日名）
  日本の祝日（春分・秋分の日、ハッピーマンデー、振替休日、国民の休日、2019年即位関連・2020/2021年の東京五輪特例を含む）を、祝日法のルールで自動計算します。通信やデータ登録は不要で、将来の年も自動で判定されます。
  カレンダー・一覧・担当表・日付選択で、日曜と祝日は赤字、土曜は青字。カレンダー／一覧では日付の横に祝日名が常に表示されます。
  ※祝日法が改正された場合は、public/index.html 内の「日本の祝日」の部分を更新してください。

■ ダブルブッキング（時刻被り）の警告
  スタッフを「確定」にしようとしたとき（現場画面の確定ボタン・ステータス選択・担当表のセル切替）、同じ日（深夜またぎも考慮）にすでに「確定」の別現場があり、時間が重なる場合は、赤い警告ポップアップを表示します。
  「キャンセルして修正する」で取りやめ、「このまま登録する」で強制的に登録できます。
  どちらかの現場に開始・終了時間が未設定の場合は、同日の別現場として「重複するか判断できません」と表示します。
  また、現場の開始・終了時間を変更して確定済みスタッフと重なった場合は、画面下部に注意メッセージを出します。
  （「打診」「〇」など確定前のステータスでは警告しません）

■ 配置依頼書の機能強化
  ・まとめ出力：配置依頼書の出力画面で「現場ごとにまとめて1シート」を選ぶと、家政大学など日々ある案件を、月内の全日分・全スタッフを1つの配置依頼書にまとめて出力します（日付の列が付きます）。現場をタップした画面から開くと、その現場だけをまとめます。
  ・手当の金額：出力画面で「移動手当」「手当」の初期値（円/人・日）を指定でき、金額の列に入ります。「手当計」列と、最下行の合計（通常給・残業代・深夜残業代・移動手当・手当・手当計・合計金額）に自動で反映され、「合計金額」にも加算されます。Excel上で人ごとに直すと再計算されます。

■ 注意
   ・同じ項目を同時に別の人が編集すると、あとから保存した内容が残ります
   ・CSVの取り込み／出力はPCのみ。キャスナビCSVの全データ（口座等）はサーバーに送らず、取り込んだPCのブラウザ内だけに保存されます
   ・念のため、定期的にPCから「バックアップを書き出す」で控えを保存してください
   ・無料枠にはリクエスト数の上限があります（画面を開いている間だけ15秒ごとに確認します）
   ・ブラウザ内だけで動かす簡易モード：public/config.js を  window.APP_CONFIG = { api: "local" };  にすると、サーバーなし（同期なし）で動きます
